## Running Locally

Clone the repository and open `index.html` in a browser. No build step is required.

```bash
git clone https://github.com/Wokulo/Okush-porfolio.git
cd Okush-porfolio
open index.html
```

## Deployment

This is a static portfolio. Deploy by enabling GitHub Pages in the repository settings, or push to any static hosting service.
